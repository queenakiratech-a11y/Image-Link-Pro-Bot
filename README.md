# Image To Link Bot

Telegram bot that converts uploaded images into direct ImgBB links.

## Railway environment variables

Set these variables in Railway:

- `TELEGRAM_TOKEN` = your Telegram bot token
- `IMGBB_API_KEY` = your ImgBB API key
- `CHANNEL_USERNAME` = your Telegram channel username without @

## Important

Never publish your Telegram bot token or ImgBB API key in GitHub or inside the source code.
